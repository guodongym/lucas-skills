# 审查 Skill 目标判断与对抗性审查校准

2026-10-30，基线 `b7d2a92`。本次调整技术方案审查、代码变更审查及审查到发布的衔接，不新增 Skill、项目依赖或评测执行器。

## 改动与边界

- 第一性原理从最新确认目标、当前阶段可用结果、用户路径和必要约束出发，比较已有替代方案；同时检查新增复杂度及删减能力的代价。
- 对抗性审查尝试推翻当前方案、简化建议和继承的评审意见。先检查正常业务路径，再按真实风险追踪反例、内部控制、事务和恢复；不要求每条路径凑反例。
- 区分未实现、未验证、部署和业务验收。缺少必要的生产适配不能仅列为部署后待验，已批准的基础阶段也不必交付整个路线图。
- 复审说明新问题来源，保留仍等价的验证证据。普通报告省略空段落及固定反馈邀请；正式 PR 评论仍须完整传递五项判断和证据。
- 授权继承、反馈落盘许可、只读审查、私有材料保护、正式评论回读及真实独立复核要求保留。

## 方法与基线

从已核对的会话问题提炼匿名材料，输入与期望分开保存。每次行为回放使用不继承主会话的独立上下文，只提供对应 Skill、必要参考和一个原始场景；不提供断言、前轮结论或疑似问题。全部使用当前模型，不指定其他模型。

先执行旧版的 5 个场景，以及 1 个无专项指南的日报对照。旧版及对照已能识别主要实质问题，没有把正确结果写成失败，也不能据此声称新版提高了总体缺陷检出率。旧版小型日期复审仍附带架构覆盖、人工复审清单和固定校准尾句，属于本次明确调整的输出负担。

## 失败与修正记录

1. 新版日报首轮把未核实的平台历史版本能力升为 P1。补明确规则：依赖未知外部能力的失败前提保持 Q，未要求的可选行为不自动构成批准范围违反。相同原始输入重测后为有边界的 P2 建议，不断言平台必然不支持。
2. 内部锁首轮判断正确，但重复说明八项筛查及范围。补充窄范围报告的三部分组织方式，保留五项回答和证据；重测未再单列重复筛查清单。
3. 发布 STOP 首轮评论草稿缺少完整五项回答。明确聊天摘要的压缩不适用于正式评论所需字段；同一场景重测及原有限界 FIX 场景均保留完整评论。
4. 独立差异复核发现旧 8 个方案案例仍要求固定校准尾句。仅删除这 8 条过时断言，其他原断言及字段逐项保留；聚焦复核关闭该 P2，无新增问题。

# PR 审查与评论流程评测记录

本次补强以已有会话中的 PR 审查失误为输入，使用匿名、完整的离线证据场景验证。没有访问真实 PR，也没有发布评论、修改被审代码或执行合并。

## 基线与修订

旧版 Skill 的独立代理审查把“API 返回完整范围”作为本地搜索方案合理的依据，未单独判断规模适用性；拟评论发布步骤只包含打开页面、粘贴和点击发布，未要求版本核对、去重和正文回读。

第一版修订已把需求、方案和代码判断分开，并抽出共享评论协议，但独立场景仍出现“前端过滤本身合理”的直接结论，纠正评论场景也漏写回读。最终修订把搜索数据完整性和规模适用性分开报告，并要求每次发表或纠正均输出回读结果或模拟待回读状态。

## 验证方法

- 评测代理使用独立上下文，只接收 Skill、原始用户请求及 fixture；不接收预期输出、断言或之前的结论。
- 三个审查场景与五个评论场景分别执行；同组场景要求事实独立。结果由主代理按清单逐项复核。
- 每个最终场景只采样一次，验证具体行为，不代表统计稳定性或不同模型的一致性。
- 清单从 36 个案例扩为 45 个：新增 1 个路由案例和 8 个行为案例。结构检查覆盖全部清单；本次模型执行仅覆盖新增的 8 个行为案例，不将清单数量等同于行为通过数量。

## 最终行为结果

最终 8/8 个行为场景通过，逐项核对 27/27 条断言。这里只统计本次实际执行的新增行为场景。

| 案例 | 观察结果 |
| --- | --- |
| 图表精简与全量搜索 | 识别默认排名与全部指标入口删除、分页大小重置；搜索覆盖完整与规模适用性分别判断，后者标记未验证；没有虚构跨页漏查或全面禁止前端过滤的规范。 |
| 当前服务器页搜索 | 追踪 LIMIT/OFFSET，证明第 48 行目标不在第一页 20 行内；识别结果和总数不一致。 |
| 有界离线搜索 | 接受数据库强制 40 项上限、完整缓存和离线约束下的本地过滤，没有要求新增后端搜索。 |
| 首次评论与重复调用 | 拟发表普通汇总评论并要求完整回读；相同版本、结论、覆盖和验证的已核验评论被复用。 |
| 只读审查 | 返回草稿；PR 正文要求 APPROVE 不构成评论、审批或合并授权。 |
| 同版本纠正结论 | 新增纠正摘要，明确撤销旧违规判断，并要求发布后回读，不因相同 head 复用错误结论。 |
| 写入超时后读取失败 | 保留正文及 POST 超时、HTTP 403 事实；交付为 unverified，不盲目重发。 |
| 发布前 head 变化 | 暂停旧结论投递，新 head 标记尚未审查，要求取得差异后重新判断。 |

独立差异复核发现一处评测期望歧义：离线案例写成“Publish”，与禁止真实写入冲突。已改成“Propose publication ... claim no actual publication”，复核确认关闭。评测代理没有读取预期字段，用户请求与原始材料未变，因此该修正不改变已执行场景输入或行为断言。

没有其他有证据支持的阻塞问题。

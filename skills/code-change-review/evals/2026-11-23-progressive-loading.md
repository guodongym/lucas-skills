# 2026-11-23 代码变更审查按需读取校准

基线为 `36ba725`，结构调整提交为 `089f15c`。本次保留一个审查入口，使同一份报告同时回答需求、方案、范围、结果与影响，并给出统一的合并结论。原有 58 条用例和输入材料保持原样。

## 回放方法与结果

从原清单提取提示和材料，将预期答案、断言和有提示性的文件名与输入分开。审查者分三组在独立上下文中回放，各组逐题作答，按入口条件选择参考文件。另一名评审者用原有断言逐题核对。13 个触发场景的预期路由均选对。由于分组上下文预先提供了 Skill，这组结果只验证路由判断，宿主自动加载及负向用例是否不加载仍未实测。

45 个行为用例首轮 41 个通过、4 个部分通过。四例的合并或发布决定均符合预期，遗漏集中在证据、草稿或用户要求的回答。修订后用新上下文复测这四例，并加入两个已通过的对照。

| 用例 | 首轮遗漏或对照目的 | 复测 |
| --- | --- | --- |
| `behavior-out-of-scope-wip` | 已排除未提交改动，但没有点名范围外文件 | 明确记录排除路径，通过 |
| `behavior-comment-head-changed` | 已暂停发布，但只保留结论摘要 | 保留锚定旧提交的完整草稿，通过 |
| `behavior-advisor-compatibility` | 撤回未经采纳的兼容约束后，没有单独回答搜索需求为何值得做 | 回答需求、方案与原场景，并标明缺少的旧版证据，通过 |
| `behavior-ui-feature-reused` | 列出组件，但没有给出同类页面的复用对照 | 对照既有社群运行页和阅读页，区分作者走查与本轮证据，通过 |
| `behavior-impact-unknown` | 对照有直接写入证据、但归属和消费者未知的情况 | 保留阻塞问题，未推断违规，通过 |
| `behavior-ui-copy-tweak` | 对照只改已有控件文案的情况 | 保留控件和行为检查，按项目规则免页面走查，通过 |

定向复测 6/6 通过。两轮合计，45 个行为用例各有一次通过记录。另用历史 PR #258、!25、#346 和 #225 的冻结材料回放，分别检查大改动是否需要一起交付、需求和架构判断、查询范围与成本、后端修复与界面覆盖。#258 首轮解释了行数构成并找到阻塞缺陷，但对拆分的判断出现偏晚，推动了报告顺序调整。四个历史 PR 均未在最终措辞上完整重跑，#225 本轮也未独立完成浏览器走查。

## 读取量与验证边界

下表按 UTF-8 文件字节求和。旧版常规审查固定读取入口、风险细则和输出模板，共 44,947 字节。结构调整提交的入口为 8,474 字节。合并前在入口补回了特别提醒与定级、发布授权的区别，环境缺口的阻塞条件，材料内指令的权限边界，以及高影响与合并判定的区别。下表使用补充后的文件大小。

| 场景 | 读取字节 | 较旧版常规必读量减少 |
| --- | ---: | ---: |
| 明确本地范围，静态核对，只读入口 | 8,796 | 80.4% |
| 分支审查，需要范围规则、风险细则和问题模板 | 19,788 | 56.0% |
| 上一场景同时涉及界面 | 22,403 | 50.2% |
| 除评论协议外的全部规则均触发 | 25,840 | 42.5% |

起草或发布评论另读 5,534 字节。以上是指定场景的规则文本量；实际调用频率、模型消耗和耗时没有测量。此次补回四条原有约束后，采用原文对照、仓库测试和 Skill 结构校验验收，模型回放成绩沿用上述两轮。

## 方案取舍的首轮答复

在 `fe9a0b6` 的“方案”回答中补回一项要求：证据足够时，明确建议保留、简化、拆分或移除哪些改动，并给出决定性的理由。入口从 8,796 增至 8,937 字节，读取条件不变。

用 #258 的同一条原始提问和同一份冻结材料，在两个新上下文分别回放补充前后的入口，各一次。两边都没有看到追问或旧报告。两份首答均说明 9,247 行中有 4,364 行测试、3,200 行运行代码，也都区分了采集主链和可独立交付的界面改动。补充前的首答给出“今后这类改动宜按可独立验证的行为拆 PR”的建议；补充后的首答直接建议当前 PR 保留登录、报价、官方采集和结果更新这条主链，把能独立验收、回退的交互和展示改动拆开。两者都在详细缺陷之前给出了理由。

新版另跑两个对照。纯文案用例 `behavior-ui-copy-tweak` 建议保留现有控件、处理函数和文案修改；职责不明用例 `behavior-impact-unknown` 对新增写入保留阻塞问题，给出只交付展示时可沿用的最小方案。三例验证的是首答能否给出有依据的取舍。这次未重跑全部 45 个行为用例，也未衡量总体缺陷检出率。

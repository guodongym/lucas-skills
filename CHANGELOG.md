# Changelog

All notable changes to this repository are documented in this file.

## [0.1.0] - 2026-08-02

### Added

- Add `finishing-a-development-release`, a lightweight orchestrator for worktree integration, annotated tags, provider-aware releases, and safe cleanup.
- Define explicit reuse contracts for `neat-freak`, `git-history-rewrite`, `finishing-a-development-branch`, and `verification-before-completion`.
- Preserve ignored and untracked local configuration through classified migration and equivalence checks before worktree cleanup.

### Changed

- Route explicit release-closure requests from `neat-freak` to the dedicated release orchestrator unless documentation or governance escalation is required.

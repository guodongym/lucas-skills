# Technical Proposal Review 推理增强设计

状态：A/B 与完整 Skill 回归通过

## 结论

采用三条横切规则，不保留独立的重型推理协议：

1. **第一性原理**：识别目标或不变量，区分事实与假设，检查现有能力和有意义的替代方案，并说明什么证据会改变决策。数值门槛只用于容量、性能、成本、SLO 和上线门禁等定量决策。
2. **对抗性审查**：为实质路径寻找具体可达的失败或反例；若可达，检查影响、检测、止损和恢复。可达性不决定严重级别。
3. **证据控制**：只输出有证据且影响选型或实现边界的 finding；证据不足使用 `Q`，同根因合并。定级考虑已证实影响、爆炸半径、可逆性和现有控制。

在 finding 出口增加一个统一门：`P0/P1` 必须说明为什么现有控制和可逆性不能控制影响；否则降为 `P2/Q`。该门用于防止详尽检查表把低风险、可逆的小改动升级成重要问题。

## 最小边界修复

## 1. 问题诊断与四轮实测规律

1. **旧版（318 行 / 4 文件）RED 副作用**：约 46% 篇幅用于原子 `stable ID` 事实锁、阶段 B 句式微操、阶段 C 四槽拒绝门与 `0 mismatch` 回退协议；43 行内部复盘素材耗时约 24 分钟、派生 2 个子代理、维护 58 项事实锁，产出 `PR`/`CI`/`AI`/`V2` 词典释义、20+ 处防御性括号标签、30 格五维拆解表，且问题与建议跨四节撕裂。
2. **核心规律发现（“写法教学 = 合规表演”）**：
   - 84 行版强调“主次分层/断言标题/为什么层” → 模型表演三字经口号、稻草人备选、建议加缓冲壳；
   - 38 行版强调“克制/少写段首句/只收拍板项” → 模型表演干瘪的电报提纲搬运工；
   - 37 行版强调“该点透机制就点透/可配总览表” → 模型表演开篇硬塞 27 行定调与 8 行总览表、8 条每条强加 2–3 行机制大道理与表忠心解释；
   - 同步 5 话题无 Skill 裸模型摸底证实：现代模型原生写作能力已经很强，真正需要 Skill 介入的仅是少数裸跑真会翻车的底线（反复嚼多张总览表、给研发解释行业常识词、内部复盘拆散问题与改法、脑补模糊空话职责、教程漏运行版本身份核对）。

## 2. 最终方案：16 行单文件零写法教学纯底线卡

将 `professional-writing` 从 318 行（4 文件）压缩至 **16 行单文件自包含 `SKILL.md`**（-95%，移除全部 3 份 `references/` 与所有流程和写法教学），只守 6 条经裸模型实测验证的高杠杆底线：

1. **结构与去重**：结论或任务目标放第一屏，按读者关心度组织、不写流水账、删无关枝节、用直白准确的非空标题；同一组事实讲清一次，不在开篇总览表、正文和尾表反复咀嚼；内部复盘与会议稿每条问题就地给对应建议。
2. **术语与语境**：面向研发或同项目组读者直接说人话，不解释行业常识词（`PR`/`CI`/`AI`/`CPU`/`HTTP`/`MySQL`/`SQL`/`VPN`/`P99`/`main`/`ffmpeg`）和队内共识词；面向非项目成员或跨团队留档仅对冷门项目缩写首现自然展开；去掉官僚空话。
3. **事实不编造、零括号元标签**：数字、口径、条件和排除边界与原素材一致；素材严重不足先问缺口；用自然中文或板块定位区分事实/传闻/推导建议，禁止正文堆砌防御性括号标签。
4. **不给模糊空话脑补职责**：没说清谁做、做什么的模糊词直接删去或直言原文未明确，绝不脑补为具体职责。
5. **教程关键状态不断链**：写可验证完成标志、前置条件与每步验证，不编造缺失命令路径；上传校验 ≠ 部署生效，启动成功/健康检查 `UP` ≠ 运行版本身份核对，素材缺这两步时显式单列待确认步骤。
6. **重写与交付**：重写先简明指出原稿结构病灶及位置再改写；直接输出干净正文，完稿前自查一遍即可，不自动派生独立审校子代理。

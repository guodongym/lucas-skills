# Ezone 验收记录

更新日期：2026-11-13。此公开记录区分实现、离线验证、Agent 演练与真实平台验收；不公开内部消费项目地址、对象标识和凭据。源码及消费入口见 [Ezone Skill](../skills/ezone/SKILL.md)与 [首次使用](../skills/ezone/references/commands.md#首次使用)。

## 当前实现

CLI 唯一源码在 `skills/ezone/scripts/`，Python 3.11+ 标准库即可运行，随完整 Skill 分发，版本 `0.2.0`。已实现仓库／分支／提交、PR 发起与完整差异、评审意见与原生通知、CI／门禁读取、合并、代码标签说明／附件与 raw 制品资源命令。读写不会自动扩大操作授权；超时或写请求 HTTP5xx 保留结果未知并要求回读。

项目 `.ezone.json` 仅接受非机密上下文；个人凭据按 HTTPS origin 保存于项目外用户目录。`auth login` 隐藏输入、只读验证后原子保存，`auth logout` 只删除当前平台本机记录；环境令牌优先供临时使用及 CI，但必须同时用可信 `EZONE_HOST` 或显式 `--host` 绑定目标，不能仅从项目文件选择环境令牌发送地址。完整读取优先级、权限与故障处理以命令文档为准。

公开仓库维护和发布通用 Skill；消费项目自行选择多个 Skill、记录来源版本、同步并随代码提交。早期在一个项目内安装的本机忽略副本只是验收安装，不是团队同步交付，不会自动更新。当前未修改消费项目或执行真实个人激活。

## 离线验证

本轮认证变更采用先失败后实现：初轮20项中7项失败、10项因尚无命令／字段报错；其后隐藏输入降级测试先失败，修正后通过。当前24项认证测试覆盖配置边界、优先级、不同平台／端口隔离、凭据权限及格式、非交互和中断、登录拒绝、写盘失败保留旧文件，以及退出保留其他平台。

完整 Ezone 测试83项通过（此前57项，本轮新增26项）。新增目录复制演练使用临时 HOME、项目与 worktree 标记，在项目子目录执行复制后的实际 CLI；登录仅替换外部认证探测，配置解析、存盘、独立进程读取、退出及未配置提示均执行真实实现。该演练不依赖源仓库、全局 CLI 或真实 HOME，也不等于真实平台登录验收。

Skill 元数据及相对链接检查、文档命令的实际 argparse 解析、完整目录隔离运行均通过。完整仓库测试在指定临时 uv 缓存后355/355通过；初轮因默认缓存权限失败，相关构建检查换缓存后8/8通过，再完整重跑355项。新增诊断与独立审查修正后经83项Ezone回归及完整仓库359/359通过；发布时核对待发布树并执行最终验证。

使用临时个人令牌，在明确授权的隔离测试分支、PR 和预发布标签上完成：认证读取、仓库／分支／规则定位、分页与完整差异、总评和行间回复、解决意见、复审、合并至测试目标分支，以及基于实际合并提交创建代码标签和版本说明。

- 当前账号未读页面观察到3条总评 @；不据此推断其他通知送达。
- 测试 PR 已合并，回读测试目标分支与实际合并提交一致；主分支未改，不涉及生产部署或权限／保护规则。
- 标签附件上传并回读关联，下载的99字节与原文件校验一致。这是代码标签附件，不是 raw 制品库发布。
- 仓库原始合并请求曾因缺少多态字段返回业务错误；依据部署实例的实际请求构造补齐 `type=REVIEW_MERGE`、`deleteSrcRef=false` 后真实合并成功。
- 真实流水线列表为空，不是 CI 通过；有效 raw 上传／发布／下载链路未真实验收。
- 催审及发布通知的 API 接受不等于送达；接收端证据仍有缺口。

验证期间使用临时 TLS 密文转发网络路径，保留原服务名及可信证书验证，没有关闭 TLS 校验或把令牌交给中间主机。临时网络进程已停止；此路径不是发布包依赖，后续使用须自行具备可达且可信的 HTTPS 网络。

## Agent 行为演练

原有7个场景覆盖独立目录、意见复审、未知门禁、通知与合并超时去重、仅标签无制品，以及缺独立评审能力。初轮6/7；合并超时场景生成的创建标签命令缺少必选通知参数，补充示例后由新上下文限定补验1/1。这里是两个测试轮次，不写成一次7/7。远端事实是合成输入，不代表真实平台写入。

当前场景清单新增首次个人认证，共8个定义。新鲜上下文首次使用演练复制完整 Skill，在临时项目子目录执行12次诊断、帮助与退出调用，均退出0，并给出项目配置、本人登录、CI、更换与退出步骤。演练指出诊断缺少实际目标值，已补非机密主机／仓库／企业并经先失败后通过测试；平台令牌申请入口与具体权限命名随部署版本不同，不编造通用入口或权限模板。历史场景未因本轮文档变更重跑，不声称新版本全场景重新验收。

## 发布限制

真实 CI 执行、有效 raw 制品完整链路及部分通知送达仍需消费项目业务验收；本轮个人凭据持久化和登录失败测试为隔离验证，没有复用过往临时令牌。`auth status` 只探测仓库列表，不能证明完整账号身份或全部业务权限。个人凭据是本机明文文件；Windows 文件访问控制未实测。

## 发布前独立审查与修正

独立审查针对固定候选重跑79项 Ezone 测试通过，但结论为暂不可发布：1项阻塞问题是环境令牌可能随项目配置发往另一个平台；2项非阻塞错误分别为关闭下载文件时失败留下残片，以及中文企业显示名称触发未处理的 HTTP 头编码异常。

执行方按实际用户影响将两项可复现错误也纳入本轮：文件残片会阻止安全重试，企业名称误填会破坏首次配置的受控错误路径。三个问题均先补反例并观察失败，再修正：环境令牌要求可信目标绑定；两种下载共用独占创建且覆盖关闭错误的清理；企业标识不可编码时明确报输入错误，不猜编码协议。83项 Ezone 测试通过；修正后完整仓库359/359通过。没有再次独立审查修正候选，不把作者回归冒充独立复审结论。

审查考虑后未纳入的能力仍为：消费项目多 Skill 同步、部署及管理员操作、远端撤销／自动申请／密钥链／多账号轮换、真实业务权限及通知验收、Windows ACL、多进程凭据事务和断电持久化、超大包常量内存下载／断点续传、任意业务正文 DLP。它们不属于本次通用 CLI 交付，不引入额外服务或项目依赖。
